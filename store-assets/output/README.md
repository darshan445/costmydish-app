# CostMyDish Store Screenshots

Generated marketing screenshots with labels + realistic data.

## Upload order (recommended story flow)

1. **01-hero-dashboard** — Hook: know food cost % at a glance
2. **02-wizard-dish** — Step 1: name dish & set target
3. **03-wizard-ingredients** — Step 2: add ingredients with buy prices
4. **04-wizard-price** — Step 3: multi-format selling prices
5. **05-live-margin** — Result: food cost % & dish profit
6. **06-ingredient-breakdown** — Per-ingredient cost breakdown
7. **07-dishes-filter** — Filter On Target vs Over Budget
8. **08-ingredient-library** — Ingredient library syncs all dishes
